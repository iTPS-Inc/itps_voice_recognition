Bilingual ASR · Realtime Interpretation

英語の講義を、日本語へ。話しながら、その場で。

iTPS の音声認識プロジェクトは、日英バイリンガルの音声認識モデルの研究と、gpt-realtime を用いた英日リアルタイム同時通訳 Web アプリで構成されます。ブラウザのマイク音声が、その場で自然な日本語字幕になります。

What it does

研究モデルと、実運用アプリの両輪

学習用のデータセット基盤・訓練スクリプトから、聴衆にそのまま見せられる翻訳アプリまでを一つのリポジトリで扱います。

リアルタイム同時通訳

ブラウザのマイクから WebRTC で音声を送り、英語の書き起こしと日本語訳を発話とほぼ同時に表示。プロの同時通訳者を想定した訳出方針で、意味を落とさず自然に。

統一データセット基盤

dsets モジュールが自動ダウンロード・キャッシュ・整形を担い、text と filename 列を保証。日英の複数コーパスを一つの API でまとめて扱えます。

訓練とチューニング

日本語・英語それぞれのスクラッチ学習ノートブックと、Optuna によるハイパーパラメータ探索を収録。研究から評価までを再現可能な形で。

Architecture

音声はサーバを通らない。鍵もブラウザに渡さない。

サーバの役割は「短命なエフェメラルセッショントークンの発行」だけ。音声とイベントはブラウザと Realtime API が直接やり取りし、本物の API キーはサーバの外に一切出ません。

Browser マイク音声 WebRTC で直接接続。localhost / HTTPS 上でのみ動作。
audio
Realtime API 書き起こし + 翻訳 whisper で英語を文字化し、gpt-realtime が日本語へ訳出。
text
Browser 日本語字幕 EN / JA を色分けして表示。MP3 と XLSX に書き出し可能。

セキュリティ設計。 認証情報は環境変数としてサーバ側にのみ保持され、ブラウザにはその都度発行される短命トークンだけが渡されます。音声データはサーバを経由せず、この紹介ページ自体も静的で外部通信を一切行いません。

Interpretation pipeline

「読める字幕」にするための作り込み

単なる直訳ではなく、聴衆がそのまま読める品質を狙った処理をパイプラインに組み込んでいます。

VAD タイミング調整

発話区切りの検出しきい値や無音長をスライダーで調整。区切りが早すぎ / 遅すぎる問題をその場で最適化できます。

フィラー・言い直しの除去

"um" や "you know" などのつなぎ語、言いよどみや言い直しを訳出から除外。最終的に確定した内容だけを日本語にします。

MP3 + XLSX 書き出し

セッションの音声を MP3 で、EN/JA の対訳ログを XLSX で書き出し。あとから議事録や教材として再利用できます。
